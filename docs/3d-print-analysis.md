# 3D 打印件稳定性与承重分析：计算方法和实现参考

本文供接手 `mz-3d-viewer` 的开发 agent 使用。基于 2026-09-30 的项目代码检查编写，是实现方案，文中标为“建议”的文件和接口尚未实现。开始开发前重新检查实际代码和仓库指令。

目标：让用户导入打印件模型，确认尺寸和使用姿态，设置重量与加载位置，判断能否自立、加载后是否倾倒；后续通过结构求解估算变形和承载能力。

## 1. 交付范围与阶段

| 阶段      | 回答的问题               | 计算方式                  | 运行位置               |
| ------- | ------------------- | --------------------- | ------------------ |
| A：静态稳定性 | 放在桌面上能否站稳；添加重量后是否倾倒 | 实体重心、实际接触区域、组合重心、倾倒力矩 | 浏览器，本地离线           |
| B：动态演示  | 怎样倒下、滑动、碰撞          | 刚体动力学、摩擦、碰撞           | 浏览器，按需加载物理引擎       |
| C：结构承重  | 会不会弯曲、压坏、断裂         | 有限元、材料强度、打印方向、边界条件    | 优先本地求解服务；可另评估 WASM |

先闭合 A 的完整用户流程。A 无须引入刚体引擎或有限元后端。

A 的首版范围：单个刚性打印件、水平刚性桌面、固定摆放姿态、仅受重力；用户添加的载荷用“重量＋竖直作用线位置”表示。初始几何支持一个经过检查的闭合实体边界；复杂多实体、嵌套独立壳体和未连接装配先明确返回无法自动分析。

阶段 A 的“稳定”只表示当前简化条件下的静态抗倾倒结果。界面将结果命名为“静态稳定性”和“倾倒临界载荷”，结构承载能力在阶段 C 单独显示。

## 3. 物理单位与坐标：先处理，再计算

### 3.1 统一计算单位

分析内部统一使用 SI：长度 m、质量 kg、力 N、密度 kg/m³、应力和弹性模量 Pa。界面可显示 mm、g、kg、MPa。

```text
1 mm = 0.001 m
1 g = 0.001 kg
1 MPa = 1,000,000 Pa
g = 9.80665 m/s²
重量产生的重力 F = massKg × g
```

设 `k` 为“查看器世界坐标长度 → 米”的比例。在烘焙完整导入变换之后，所有参与分析的位置乘 `k`。不要对已烘焙的 3MF 再乘一次声明单位。

| 格式                 | 当前行为                      | 分析要求                                   |
| ------------------ | ------------------------- | -------------------------------------- |
| 3MF                | 声明单位已折算到毫米                | 正常单位处理成功时 `k = 0.001`；未知单位仍需确认         |
| STL / OBJ          | 当前按毫米读数，通常缺少可靠物理单位        | 提供 mm / cm / m / in 选择和尺寸预览            |
| glTF / GLB         | 当前 loader 保留导入数值，查看器读数按毫米 | 标准 glTF 的长度单位是米；默认分析比例为 `k = 1`，允许用户核对 |
| STEP / IGES / BREP | 当前查看器按毫米读数                | 用已知尺寸样件验证导入引擎的单位归一化；未确认前不能仅凭扩展名认定单位    |

glTF 的米制单位见 [Khronos glTF 2.0 规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.pdf)。分析面板应先显示确认后的物理尺寸，尤其是模型单位与当前查看器读数存在差异时。若修改全项目单位语义，将其作为独立的导入/尺寸改动验证。

### 3.2 分析坐标系

阶段 A 定义桌面为 `y = 0`，向上为 `+Y`，重力为 `(0, -g, 0)`，支撑多边形在 `(x, z)` 平面内。

用户选择底面后，根据检查过的三角形绕序确定实体外法线，将底面外法线旋转到 `-Y`。不要直接依赖可能缺失或仅用于平滑显示的顶点法线。曲面上的单个三角形不能自动证明存在平底。

首版建议维护一个分析姿态变换 `A`，在计算空间完成放置；不破坏导入模型的局部矩阵。对顶点：

```text
pWorld = mesh.matrixWorld × pLocal
pAnalysis = A × (k × pWorld)
```

旋转后求整个分析对象的 `minY`，平移使 `minY = 0`。若选中的底面并非真实最低接触面，指出更低的凸出部位，重新确认接触区域。

分析图层需要回到当前显示空间：`pWorld = A⁻¹ × pAnalysis / k`。桌面、重心标记和支撑边界都用同一映射。这样分析平面可以在查看器中呈现为选定底面所在平面，不必依赖原来的网格地板。

先提供明确的朝向/底面选择，再考虑自动推荐姿态。相机旋转只改变观察方式，不能改变重力方向。

## 4. 几何预处理与适用性判断

### 4.1 获取完整、未展开的实体

进入分析时，在 `Stage` 内结束当前模型的展开动画并精确还原，不能只改 UI 滑块。确认 `explode = 0` 且没有未完成过渡，然后更新世界矩阵。

默认分析整个当前模型；零件隐藏和隔离是显示操作，不应偷偷移除物理质量。若提供“只分析选定零件”，必须在界面明确标出分析对象；列表中的一个网格可能仅是一块 CAD 面，不能自动当成实体。

逐个读取 Mesh 的 `position` 与 `index`，支持索引和非索引几何，正确读取交错属性。应用完整 `matrixWorld`，避免漏掉父节点的旋转、缩放和镜像。多个共享几何实例分别烘焙各自的变换。负行列式的变换需调整三角形绕序，以保持边界朝向一致。

首版对带骨骼或形变的模型明确拒绝，或先实现当前姿态的几何烘焙；不能使用未变形顶点却显示当前姿态的分析结果。

### 4.2 检查要求

在分析副本上焊接同位置顶点以检查拓扑；保留原始显示几何、材质、UV 和法线。STL 以及按材质/CAD 面拆开的模型经常存在同坐标的重复顶点，不能仅按 BufferGeometry 索引判定开口。

焊接采用空间分桶并比较真实距离，不能只四舍五入坐标后认定相同。容差根据物理尺寸和导入精度设定，并记录在结果中。不要用大容差把真实裂缝或薄壁焊掉。

必要检查：

1. 顶点与变换有限、三角形索引合法、面积非退化。
2. 每条无向边有两个相邻三角形，且相邻面的边方向相反。
3. 检查顶点邻域，排除仅在顶点相连的非流形情况。
4. 边界朝向一致；修正局部绕序需在分析副本上完成并报告。
5. 检查自交和重复/重叠面；闭合边检查本身不能证明实体有效。
6. 识别连通边界和体积，检查零体积、多个独立实体与嵌套壳体。

对自交检测等较重步骤，可以使用空间加速的可靠几何实现。若首版未实现完整检测，必须输出“几何有效性未完整验证，仅供估算”，不要把未检测解释为已通过。严重问题返回无法分析及原因。

首版不自动补洞、不自动合并相交实体、不自动推断装配刚性连接。存在内腔的多重嵌套边界需按实体/空腔关系处理体积符号，不能将每个壳体取绝对体积后相加。单一连通边界也可以描述带孔实体，不能按“凹形或有孔”一律拒绝。

闭合三角网格的体积计算、边界方向和自交处理可参考 [CGAL Polygon Mesh Processing](https://doc.cgal.org/latest/Polygon_mesh_processing/)。它提供算法依据；首版无需直接引入整套 CGAL。

## 5. 体积、质量与重心计算

### 5.1 均匀实体的有符号四面体积分

对一致定向、无自交的闭合边界，取靠近模型的参考点 `o`，例如分析坐标包围盒中心，减小大坐标下的数值抵消。

对每个三角形顶点 `a, b, c`：

```text
u = a - o
v = b - o
w = c - o

Vi = dot(u, cross(v, w)) / 6
Ci = o + (u + v + w) / 4

V_signed = Σ Vi
C = Σ(Vi × Ci) / V_signed
V = abs(V_signed)
```

`Vi` 是有符号量，凹实体允许部分贡献为负。不能对每个 `Vi` 取绝对值。对整体反向边界，分子与分母同时变号，重心不变。若总体积接近零或符号抵消异常，先检查几何和朝向。

用 JS Number/Float64 累积，较大网格考虑补偿求和；最终精度仍受导入的 Float32 顶点限制。闭合多面体质量属性的积分思路见 [Mirtich 原始论文](https://www.cs.upc.edu/~virtual/SGI/docs/3.%20Further%20Reading/Fast%20and%20accurate%20computation%20of%20polyhedral%20mass%20properties.pdf)。

均匀密度实体：

```text
massKg = densityKgPerM3 × volumeM3
```

不要将包围盒中心、表面顶点平均值或表面积加权中心当作实体重心。非均匀三角形细分会使顶点平均值产生明显偏差。

### 5.2 打印件质量输入

首版提供两种质量来源：

- 用户填写实测重量或切片器估算重量，优先使用。
- 按均匀实心实体和密度估算，明确显示该假设。

实测重量能改进与外加载荷的质量比，但不会自动修正内部非均匀分布造成的重心偏差。质量来源和“重心按均匀实体估算”分别标注。

不能直接使用 `实心质量 × 填充率` 作为可靠打印质量；外壁、顶底层和局部设置会影响材料分布。也不能把填充率当成强度折扣系数。[Prusa 填充说明](https://help.prusa3d.com/article/infill_42)说明了外壁与填充对力学表现的不同影响。

后续若要改进重心，可解析实际切片路径并按挤出截面积、路径长度和材料密度积分；读取 G-code 时还需处理绝对/相对挤出、回抽、移动和重复挤出，不能简单相加 E 值。

已知多个刚性连接、互不重叠实体的质量与重心时：`C = Σ(mj × Cj) / Σmj`。首版不自动认定导入装配具备这种连接关系。

## 6. 接触区域与支撑多边形

### 6.1 提取真实底部接触

放置后桌面为 `y = 0`。沿完整几何寻找接触该平面的三角形、边和顶点，处理与平面的交点，并将接触点投影为 `(x, z)`。

数值容差 `εcontact` 用于表达导入精度和可接受的微小共面误差。仅处于 `y <= εcontact` 的候选顶点/裁剪点才可参与接触估算；不能使用所有顶点的俯视投影，也不能使用整个包围盒底面。

容差过大会把悬空脚或斜面错误地当成接触，扩大支撑范围。界面记录容差；当结果对容差敏感时标记为临界或不确定。必要时分别用较小/较大容差重算接触边界，比较结论。

### 6.2 求凸包

对接触点去重，使用二维单调链算法求凸包，得到 `(x, z)` 坐标下逆时针多边形。复杂度 `O(n log n)`。

水平桌面、刚体、只受重力且接触能提供非负法向反力时，接触点的凸包是静态支撑范围。三条腿之间的空隙可以位于凸包内部，但整件必须具有可靠刚性连接。

凸包只有一个点或一条线时，显示“点/线接触，无法按平底模型确认稳定”。球、滚轮或弧底需要检查小转动后的接触变化与势能，不能套用平底结果。

首版主要接受具有明确平面底部支撑的对象。凹凸桌面、弹性脚垫、悬挂和粘接底座留待后续模型。

## 7. 自立与加载后的静态判断

### 7.1 重心投影与边界距离

设重心 `C = (cx, cy, cz)`，竖直投影 `p = (cx, cz)`。凸包顶点为 `v0 ... vn-1`，逆时针排列。

对每条边 `a → b`，令 `e = b - a`：

```text
d_edge(p) = cross2(e, p - a) / length(e)
cross2((x1,z1), (x2,z2)) = x1*z2 - z1*x2
d_min = min(d_edge(p))
```

这里 `d_edge` 是到边所在直线的有符号内侧距离，单位 m。正数为内侧，负数为外侧。

- `d_min > εmargin`：在当前模型假设下具有静态抗倾倒余量。
- `abs(d_min) <= εmargin`：临界，不能显示确定稳定。
- `d_min < -εmargin`：当前姿态无法保持静态平衡。

`εmargin` 至少覆盖接触识别和几何精度误差，不能仅取浮点机器误差。显示最近支撑边和余量，例如“重心投影距最近支撑边 12 mm”。这个余量不是结构安全系数。

### 7.2 组合重心

模型质量 `m0`、重心 `C0`；添加载荷质量 `mi`、等效位置 `Ci`：

```text
M = m0 + Σmi
C_total = (m0*C0 + Σmi*Ci) / M
p_total = (C_total.x, C_total.z)
```

首版的 `Ci.x/z` 表示竖直载荷作用线；`Ci.y` 仅用于示意或后续刚体质量分布。固定水平支撑、仅竖直重力时，加载高度不影响倾倒判据；它会影响侧推、倾斜或动态行为。

“点击加载位置”选择实际受力位置。该首版假设载荷能够稳定传递到打印件，不负责证明上方物品本身不会滚落或滑落。后续用真实物体接触替代等效载荷时，使用物体真实质量、重心和接触关系。

### 7.3 单个位置的倾倒临界载荷

支撑区域固定，载荷位置 `pL` 固定，自重已知。对每条支撑边计算 `d0 = d_edge(p0)`、`dL = d_edge(pL)`。

```text
稳定条件：m0*d0 + mL*dL >= 0
当 dL < 0 时：mCritical_edge = -m0*d0/dL
mCritical = 所有有效边界的最小临界质量
```

先判断模型自重下是否已有余量；若已不稳定或临界，单独说明初始状态，不能输出常规的正承载上限。

若载荷投影对所有边都在内部，则本模型下没有有限的“倾倒临界质量”。输出“该位置增加竖直载荷不会由本判据触发倾倒”，结构承重保持未计算。

若已有多个固定载荷，可将其并入基础项：`B_edge = m0*d0 + Σ(mi*di)`；新增单个载荷临界质量为 `-B_edge/dL`。基础组合必须先稳定。

### 7.4 力矩和后续侧推扩展

仅重力时，绕一条支撑边的抗倾倒力矩：

```text
Mrestore_edge = Σ(mi*g*di) = M*g*d_edge(p_total)
```

若后续增加朝某边外侧的水平推力，作用高度为 `h` 且接触仍有效：`Ftip = Mrestore_edge/h`。摩擦系数为 `μ` 时，简化的平移滑动阈值为 `Fslide = μ*M*g`；需比较滑动与倾倒谁先发生。

这只是特定方向和工况的公式。任意外力、力偶或斜桌面应通过完整合力/力矩和接触约束判断。首版无需实现侧推与倾斜。

## 8. 可直接核对的数值例子

### 8.1 体积与单位

边长 10 mm 的均匀立方体：

```text
边长 = 0.01 m
体积 = 0.000001 m³ = 1 cm³
密度假设为 1240 kg/m³
质量 = 0.00124 kg = 1.24 g
```

密度值只作为算术测试输入，不代表所有 PLA 或打印参数。中心在原点时重心为原点；放到桌面后重心高度为 5 mm。

同一物理尺寸的 STL、声明 mm/in 的 3MF 和标准米制 glTF，应得到一致的分析尺寸、体积和质量。

### 8.2 加载与倾倒

支撑范围：`x,z ∈ [-50, 50] mm`。模型质量 0.2 kg，原重心投影为 `(0,0)`。载荷作用线位于 `(80,0) mm`。

```text
右边界 d0 = 50 mm，dL = -30 mm
临界载荷 = 0.2 × 50 / 30 = 0.333333... kg

载荷 0.1 kg：组合 x = 26.6667 mm，最近边余量 = 23.3333 mm
载荷 0.333333... kg：组合 x = 50 mm，临界
载荷 0.5 kg：组合 x = 57.1429 mm，越界 7.1429 mm
```

载荷改到 `(0,0)` 时，不存在有限的竖直载荷倾倒阈值。测试应检查这种结果的文案，而不将 Infinity 渲染成“无限承重”。

## 9. 代码组织、数据所有权与计算触发

### 9.1 最小实现建议

- 建议增加 `src/analysis/stability.ts`：负责分析副本的几何检查、质量属性、接触凸包与静态计算。实际消费者为 Stage 的分析入口和必要的数值测试；不依赖 DOM、渲染器或 UI 状态。
- 分析输入与生命周期归当前模型，由 `Stage` 管理。可以在现有 `ModelHandle` 增加一个按需创建的分析数据对象；不要另建按模型 ID 索引的注册表来重复持有同一数据。
- `Stage` 直接拥有分析图层、结果应用和清理。DOM 输入先接在现有 `createApp` 中；只有分析 UI 已形成独立职责时再拆文件。
- 大模型需要 Worker 时再增加 `src/analysis/stability.worker.ts`，调用同一计算模块。它的消费者为 Stage 发起的几何分析任务；参考 `createEdges` 的复制、传输、终止方式，不另建通用任务管理框架。

这些路径是建议而非既有 API。实现前检查 `stage.ts` 当前体积，避免把所有数值算法塞进已有场景模块；新模块只保留本验收流程确实调用的功能。

### 9.2 必要的数据与来源

| 值                    | 唯一来源或所有者    | 更新时机        |
| -------------------- | ----------- | ----------- |
| 原始显示几何与导入矩阵          | 现有模型 `root` | 导入/删除       |
| 物理比例、分析对象、姿态、质量来源、载荷 | 当前模型的分析输入   | 用户操作        |
| 体积与均匀重心              | 几何检查和积分结果   | 分析对象/尺寸改变   |
| 接触点与凸包               | 分析姿态下的完整几何  | 姿态/接触容差改变   |
| 组合重心、余量、临界质量         | 现有结果与载荷派生   | 重量/位置改变     |
| 图层对象与异步取消句柄          | Stage       | 分析显示/任务生命周期 |

UI 控件只映射当前模型的数据。物理比例只维护一个值，不同时存可互相推导的比例、宽高深和单位倍率。

输入是业务数据；图层和取消句柄是渲染/执行资源，不能混进发送给 Worker 的物理输入。首版无需持久化或跨会话缓存。

### 9.3 避免无效计算

```text
首次进入分析：检查几何 → 积分 → 接触凸包 → 静态结果
改变比例/分析对象：重算几何派生量与接触
改变姿态：更新重心姿态和接触，重算稳定性
改变密度/实测重量：更新质量，再算组合结果
拖动载荷/改变载荷重量：只算组合重心、边界距离和临界质量
旋转相机/切换显示单位：只更新显示
```

不要在每一渲染帧遍历所有三角形。载荷拖动时复用已获得的质量属性和凸包。

传入 Worker 的数组必须是副本，不能 transfer 正在渲染的原始 attribute buffer。取消、模型切换、删除时终止旧任务；应用结果前确认任务仍属于该模型当前的分析输入，可直接比较本次取消控制器，不需要通用版本注册表。

结果/图层变化要设置 Stage 的 `needsRender`，沿用空闲渲染行为。清理新增几何、材质和事件监听；回首页、模型删除和取消后不得出现旧标记或旧结果。

## 10. 阶段 A 的界面与完整验收流程

主流程：导入 → 打开静态分析 → 确认真实尺寸 → 选底面/姿态 → 确认质量 → 运行 → 添加载荷 → 查看变化。

建议显示：

- 模型质量及来源、实体重心假设、几何检查状态。
- 重心标记、沿重力的投影线、投影点。
- 实际接触区域、支撑凸包边界、最危险支撑边。
- 每个载荷的重量和位置、组合重心。
- 稳定/临界/不稳定/无法判断，以及最近边余量。
- 固定加载位置的倾倒临界质量；结构承重显示“尚未分析”。

使用选定平底时显示对应桌面，不让原有包围盒网格暗示物理接触。标记同时使用文字和形状，颜色仅辅助。

首版可以用表面点击加数值位置输入，不必先实现复杂拖拽 Gizmo。移动端必须能准确选择底面与加载点，提供确认/重选和数值修正。

进入分析时还原展开、关闭视觉裁剪。离开分析时清理覆盖图层，并恢复必要的原显示设置。分析期间禁止展开再次修改参与计算的姿态，或退出分析后执行展开。

阶段 A 完成条件：上述主流程可在真实浏览器操作；数值例子正确；几何或单位无法确认时结果明确；不破坏现有导入、查看、隐藏、截图、离线和空闲渲染。

## 11. 阶段 B：刚体动态演示

有了 A 的静态数据后，再考虑接入 [Rapier JavaScript 碰撞体文档](https://rapier.rs/docs/user_guides/javascript/colliders/)。其质量和重心配置见 [质量属性说明](https://rapier.rs/docs/user_guides/templates/collider_mass_properties/)。

关键处理：

- 固定地面与动态打印件使用同一米制单位和分析坐标。
- 明确设置物体质量、重心、惯量、摩擦和恢复系数。
- 凹模型使用适合动态刚体的凸分解/组合碰撞体；单个整体凸包可能把支架、容器的空隙填满。显示网格不直接等同可靠动态碰撞几何。
- 碰撞体近似后的自动质量分布可能偏离原模型，必要时使用原几何算出的质量属性。
- 固定物理步长、限制每帧追赶步数，提供复位；加载后需要真实接触的物品应作为独立刚体。
- 运动时持续请求渲染，全部休眠后恢复项目的空闲渲染。


刚体演示服务于倾倒和滑动观察，不输出打印件断裂或结构承重结论。阶段 C 与刚体引擎保持独立。

## 12. 阶段 C：结构承重与变形

### 12.1 所需输入

几何之外还需明确：材料密度、弹性模量 `E`、泊松比 `ν`、适用的强度数据、打印方向、壁厚、填充方案、层间性能、支撑约束、加载区域和载荷方向。

使用姿态与打印方向是两个输入，打印结束后的摆放旋转不能覆盖材料方向。首个结构版本可以限定“均匀实心、各向同性、线弹性、小变形、明确固定支撑”，并在结果中列出这些假设。

PLA/PETG 等名称只用于选择有来源的参数集；实际打印件需要打印工艺相符的试样数据。填充和层间黏结带来的方向性应通过经过校准的等效参数或显式结构描述，而非通用填充折扣。

### 12.2 求解流程

```text
有效实体/原始 CAD
  → 几何修复或明确拒绝
  → 四面体体网格；薄壁可选择适当壳模型
  → 材料与打印方向
  → 支撑/连接/接触约束
  → 自重与加载区域
  → 求解
  → 应力、位移、反力、质量和收敛检查
  → 结果表面映射到当前查看器
```

可采用 [Gmsh](https://gmsh.info/doc/texinfo/) 网格器与 [CalculiX](https://www.dhondt.de/) 求解器。CalculiX 的 [能力说明](https://dhondt.de/ov_calcu.htm)包含各向同性/正交各向异性材料和接触等支持；具体使用按选择的安装版本核对。也可先用 FreeCAD FEM 做可复现的离线参考工况。

项目现有 OpenCascade WASM 用于导入细分，不等同结构网格器或 FEM 求解器。需要保留/重新读取原始 CAD 文件时，明确新增文件引用的实际消费者是后续网格任务，并保持“默认本地处理”的现有产品语义。接远程服务后上传必须是明确的用户操作。

优先以单个本地任务实现“导出输入 → 求解 → 导入结果”，验证后再增加浏览器与本地服务接口，避免第一步先搭复杂任务平台。

### 12.3 计算与结果解释

线弹性静力模型：

```text
K*u = f
strain = B*u
stress = D*strain
```

`K` 为装配并施加约束后的刚度矩阵，`u` 为节点位移，`f` 包含自重与载荷。自由刚体模式未约束时系统可能奇异，需检查边界条件。

“放在桌面上”与“底面粘死”采用不同边界条件。自由放置需要允许接触张开，并按工况考虑滑动；若首版只能做固定支撑，要求用户明确选择这个工况，不能默认固定整个底面来代表自由放置。

载荷施加在实际接触面积，按压力或分布力表达。单节点点力和尖角可能产生应力奇异，不能直接用最大应力换算承载上限。

均匀各向同性材料在合适的延性屈服模型下可用 von Mises 等效应力和允许应力比较。脆性破坏、层间开裂、各向异性打印件需要相应失效准则，不能统一用一个 von Mises 阈值。

至少报告：最大位移、关键区域应力、反力平衡、网格质量、材料与约束假设；展示变形时标明放大倍数。用两到三个网格尺度检查关键量收敛，避免只显示一个精细彩色结果。

固定边界、线性材料且无接触状态变化时，载荷响应可按比例缩放，但有自重时响应是“固定自重响应＋新增载荷响应”，不能把总应力简单乘载荷倍率。存在屈曲、大变形、接触改变、塑性或长期蠕变时需重新求解合适模型。

输出工程承载建议前，还要结合位移限值、适用失效准则、工况安全系数和打印样件测试。长期承载与温度影响作为单独工况处理。

## 13. 验证与执行顺序

### 13.1 必要的算法用例

这些测试验证物理结果与已知边界，避免只重复实现细节：

- 立方体和四面体的解析体积、重心；平移、旋转后对应变换正确。
- 索引/非索引几何、重复 STL 顶点、父节点变换、镜像实例。
- 相同物理尺寸的不同格式/单位输入得到一致结果。
- 凹实体的体积积分，验证每个四面体贡献不能取绝对值。
- 支撑多边形内、边界和外部；三脚支撑、点/线接触、悬空脚。
- 第 8 节的载荷例子和没有有限倾倒阈值的情况。
- 开口、自交、非流形、零体积和不支持的嵌套壳体能正确返回无法判断或受限结果。

### 13.2 浏览器验收矩阵

| 工况 | 验证内容 |
| --- | --- |
| 桌面主流程 | 选底面、核对尺寸、设置质量、添加载荷、跨越临界点 |
| 移动端主流程 | 触摸选择、数值修正、面板与相机操作 |
| WebGPU / WebGL2 | 图层、射线拾取、截图和标记位置一致 |

### 13.3 按仓库要求闭合批次

1. 先检查完整调用链，确定几何、输入、Stage 图层和 UI 是同一核心批次。
2. 实现期间运行类型检查与必要数值测试；早期浏览器只做定向 smoke。
3. 核心批次连通后运行一次完整浏览器矩阵；问题做最小修正并复查受影响场景，稳定后完成矩阵。
4. 行为通过后清理无消费者的类型、字段、文件和转发函数。
5. 最后集中执行项目要求的格式检查、类型检查、构建和相关验收。当前 package.json 没有 lint/format 脚本，不为此无故新增工具链。
6. 清理若改到运行时代码，补定向浏览器 smoke；影响主要流程时再跑完整矩阵。

现有命令按实际改动选用：`pnpm typecheck`、`pnpm build`、`pnpm verify`、`pnpm verify:tools`、`pnpm verify:loading`。后两者需要可访问的运行服务，按 README 传入 URL。最终验证集中进行，避免每改一个组件就跑全部慢检查。

最终报告列出实际复用入口、新增模块的真实消费者、数值验证结果、浏览器验证结果，以及仍未支持的工况。浏览器可访问时必须验证受影响页面后再宣告功能完成。
